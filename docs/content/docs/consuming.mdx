---
title: Consuming the API
description: Reflective lookup (recommended) and Gradle compile dependency (discouraged).
---

Two ways to call Perfect Utils' APIs from another mod:

- **Gradle compile dependency** — simple, but breaks consumers when Perfect
  Utils isn't installed and runs into Hytale's plugin classloader isolation.
- **Reflective lookup at runtime** *(recommended)* — your mod loads cleanly
  either way and degrades to a no-op when Perfect Utils is missing.

## Hard dependency (discouraged)

<Callout type="warn" title="Why this is discouraged">
Hytale's plugin loader gives each mod its own classloader, so a direct
compile-time reference can fail to resolve at load time even when Perfect
Utils is installed. And if it isn't installed at all, the consumer mod fails
to load — no graceful degradation. Fine for sibling-repo dev where both jars
are always present; not for published mods.
</Callout>

The jar is published on
[CurseForge](https://www.curseforge.com/hytale/mods/perfect-utils). Drop it
into a `libs/` folder in your mod:

```groovy
dependencies {
    compileOnly files("libs/Perfect Utils-1.0.3.jar")
}
```

Calls are then direct:

```java
StunMobAPI.get().applyStun(store, mobRef, 2000L, attackerRef);
```

## Reflection (recommended)

### Detect

```java
PluginManager pm = PluginManager.get();
PluginIdentifier id = new PluginIdentifier("narwhals", "Perfect Utils");
if (!pm.hasPlugin(id, SemverRange.WILDCARD)) return; // not installed
```

### Resolve

```java
ClassLoader cl = plugin.getClass().getClassLoader();

Class<?> stunClass = Class.forName("com.narwhals.perfectutils.api.StunMobAPI", false, cl);
Object stun = stunClass.getMethod("get").invoke(null);
Method applyStun = stunClass.getMethod("applyStun", Store.class, Ref.class, long.class, Ref.class);

Class<?> aggroClass = Class.forName("com.narwhals.perfectutils.api.AggroAPI", false, cl);
Object aggro = aggroClass.getMethod("get").invoke(null);
Method dropAggro = aggroClass.getMethod("dropAggro", Store.class, Ref.class, double.class);
Method suppress  = aggroClass.getMethod("suppress",  Store.class, Ref.class, long.class, double.class);
Method taunt     = aggroClass.getMethod("taunt",     Store.class, Ref.class, long.class, double.class);
```

**Cache the `Method` handles + the API instance on first lookup.**

### Call

```java
applyStun.invoke(api, store, mobRef, 2000L, attackerRef);
```

All apply/wake calls take `Store<EntityStore>` only — no `CommandBuffer`
needed. Requests queue and drain on the next world tick.
