Install Perfect Utils only when another mod requires it.

1. Download `Perfect Utils-x.y.z.jar` from
   [CurseForge](https://www.curseforge.com/hytale/mods/perfect-utils).
2. Place it in your Hytale `mods/` folder.
3. Start the server. The dependent mod picks it up automatically.

There is no configuration. Mods that consume Perfect Utils set their own
durations and radii.

## Compatibility

Works on any Hytale server. Aggro and taunt windows are tracked
**per-player** — the most recent request wins, the previous one is replaced.
