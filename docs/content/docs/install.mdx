Install Perfect Utils only when another mod requires it.

1. Download `Perfect Utils-x.y.z.jar` from
   [CurseForge](https://www.curseforge.com/hytale/mods/perfect-utils).
2. Place it in your Hytale `mods/` folder.
3. Start the server. The dependent mod picks it up automatically.

There is no configuration. Mods that consume Perfect Utils set their own
durations and radii.

## Compatibility

Each version is built for one Hytale update, and a build for one update won't
load on another:

| Hytale | Perfect Utils |
| --- | --- |
| Update 7 (server `0.7.x`) | 1.3.0 and later |
| Update 6 (server `0.6.x`) | 1.2.0 |
| Update 5 (server `0.5.x`) | 1.0.2 to 1.1.0 |

Aggro and taunt windows are tracked **per player**: the most recent request
wins, the previous one is replaced.
